## 🔬 Research Highlight

<div align="center">

### 📄 *Empirical Performance Optimization of a Django Web Application*

</div>

> A rigorous, evidence-based performance study on a **9-million-record Django backend** using Locust for load testing.

| Metric | Before | After | Improvement |
|---|---|---|---|
| Avg. Response Time | 354s | **57ms** | **🔻 99.98% reduction** |
| Throughput (RPS) | ~0 | **13 RPS** | **🔺 Near-infinite gain** |
| Primary Lever | — | Pagination | **~99% of latency saved** |

**Methodology stack:** ORM optimization (`select_related()`), pagination, view-level caching — applied sequentially to isolate impact. Demonstrated diminishing returns of caching after structural improvements.
