Django performance optimisation

Self-directed research benchmarking and tuning a Django application under enterprise-scale load — conducted independently, outside coursework.

Methodology

  • 01Ran load tests against a Django app backed by a 9-million-record MySQL dataset using Locust, simulating concurrent enterprise-level traffic.
  • 02Applied ORM query optimisation via select_related(), cutting redundant database round-trips.
  • 03Introduced pagination and view-level caching to bound query size and reuse computed responses.
  • 04Measured throughput and latency at each optimisation step to isolate its individual impact.

Findings

  • →Average response time dropped 99.98%, from 354 seconds to 57 milliseconds.
  • →Request throughput rose from near-zero to 13 requests per second under the same load.
  • →Documented a diminishing-returns analysis showing which optimisation gave the most benefit per unit of effort.
  • →Produced structured, reproducible technical documentation of methodology, metrics, and findings for future reference.
